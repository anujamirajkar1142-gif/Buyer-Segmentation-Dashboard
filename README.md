
# Real Estate Buyer Segmentation

## Project Overview
This project uses Machine Learning to segment real estate buyers based on their investment behavior and demographics.

## Features
- Customer Segmentation using K-Means
- Interactive Streamlit Dashboard
- Data Visualization (EDA)
- Business Insights

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Plotly
