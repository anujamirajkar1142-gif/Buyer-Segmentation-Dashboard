
# Real Estate Buyer Segmentation

## Project Overview
This project focuses on analyzing and segmenting real estate buyers based on their investment behavior, demographic patterns, and client profiles.
An interactive dashboard is developed to help visualize trends, identify high-value customers, and understand different buyer segments using data-driven insights.

## Objectives
* Segment real estate buyers into meaningful categories
* Analyze investment patterns across different regions
* Provide actionable insights for decision-making
* Build an interactive dashboard for easy exploration

## Features
- Customer Segmentation using K-Means
- Interactive Streamlit Dashboard
- Data Visualization (EDA)
- Business Insights

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Plotly

## Live App
https://anujamirajkar1142-gif-buyer-segmentation-dashboard-app-mr2vyu.streamlit.app/

## Key Insights
* Corporate buyers dominate the real estate market
* USA contributes the highest investment volume
* Luxury buyers show higher average spending
* Risk-averse investors prefer stable investment options

## Conclusion
This project demonstrates how machine learning concepts and data visualization can be combined to derive meaningful insights from real estate data. The dashboard helps in understanding customer behavior and supports better strategic decisions.
